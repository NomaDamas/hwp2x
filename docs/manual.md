# hwp2x 사용 매뉴얼

## 지원 환경

- Windows 10 이상과 한컴오피스 한글 2014, 2018, 2020, 2022
- 여러 한글이 설치되어 있으면 최신 버전을 사용합니다.
- Linux 패키지는 화면과 설치 구성을 확인할 수 있지만, 한글 COM 변환은 Windows에서 실행합니다.

## 설치

Windows는 Releases의 `hwp2x-setup.exe`를 실행합니다. Linux는 `hwp2x_0.1.0_amd64.deb`를 설치합니다. 설치 후 프로그램 창이 열리며 브라우저 주소는 사용하지 않습니다.

## 변환

개요 화면에서 폴더를 지정하고 파일을 찾습니다. 변환은 같은 이름의 HWPX가 있으면 건너뛰므로 재시도해도 성공한 파일은 바뀌지 않습니다. 진행 수, 진행률, 시간, 용량 변화가 개요에 표시됩니다.

## 검증과 백업

rhwp가 원본과 변환본의 문단, 표, 그림, 모양, 머리말과 각주를 비교합니다. 무손실로 확인된 원본만 백업 후 삭제할 수 있습니다. 차이가 있거나 실패한 원본은 그대로 남습니다.

## 문제 해결

- 한글이 없으면 설치 화면의 `다시 감지`를 누르기 전에 한글을 설치합니다.
- rhwp가 없거나 버전이 0.8 미만이면 검증이 별도 안내로 실패합니다.
- 손상된 파일은 변환 대상에서 실패로 표시되고 원본은 삭제되지 않습니다.
